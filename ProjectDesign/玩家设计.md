
# 1. 玩家属性设计

玩家属性包括：
- **体力值**：初始值为 5，上限为 7。
- **金钱**：初始值为 100，无上限。

当体力值为 0 时，玩家被淘汰出局。
当金钱为 0 时，玩家被抓到煤矿去挖煤两个回合，挖煤结束后金钱恢复到 100。

**挖煤状态**：玩家先扣除 1 点体力值，开始时长两个回合的挖煤。挖煤期间，玩家被限制在 `煤矿` 格子上，跳过回合的 `移动到新位置` 与 `进行特殊操作` 步骤。（一共扣 3 点体力，挖煤前扣 1 点，两个回合默认扣除 2 点）

# 2. 玩家操作设计

玩家的操作分为两种：
1. **普通选择操作**：根据移动到的格子触发事件，事件会给出不同选项供玩家选择。
2. **特殊操作**：事件触发结束后，玩家可以进行特殊操作，特殊操作包括：
   - **使用道具**：玩家可以使用道具。
   - **购买格子**：玩家可以选择购买当前所在的格子，购买后该格子将归玩家所有，并且其它玩家停留在该格子时需要支付过路费。
   - **出售格子**：玩家可以选择出售自己拥有的格子，出售后该格子将变为未拥有状态，并且玩家获得相应的金钱。

# 3. AI 设计

AI 不需要很聪明，行为可以基于简单的规则，例如：
- **优先购买**：当 AI 停留在一个未拥有的格子时，优先考虑购买该格子。
- **优先使用道具**：当 AI 体力值较低时，优先考虑使用道具来恢复体力。
